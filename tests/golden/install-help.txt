=== install.py --help ===
usage: install.py [-h] {install,update,doctor,uninstall,add-template,default-template,list-templates} ...

Install, update, check and remove the ai-dev-workflow skill (AIDevWorkflow) for each supported
agent.

positional arguments:
  {install,update,doctor,uninstall,add-template,default-template,list-templates}
    install             Install the skill (default).
    update              Refresh existing installs from this package.
    doctor              Check every installed copy.
    uninstall           Remove installs made by this script.
    add-template        Add a specification template to your private library.
    default-template    Show, set or clear your default template.
    list-templates      List your private templates.

options:
  -h, --help            show this help message and exit
