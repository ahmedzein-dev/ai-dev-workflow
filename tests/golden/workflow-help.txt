=== workflow.py --help ===
usage: workflow.py [-h] [--version] {init,new,status,discover,spec-check,review,plan-check,approve,stage,resume,pause,preflight,step,run,scope,decision,check,outcome,close,hook} ...

AIDevWorkflow engine for the ai-dev-workflow skill.

positional arguments:
  {init,new,status,discover,spec-check,review,plan-check,approve,stage,resume,pause,preflight,step,run,scope,decision,check,outcome,close,hook}
    init                Set up AIDevWorkflow in a project (after asking the user).
    new                 Create a task (only after an explicit invocation).
    status              List tasks, or show one task with its next step.
    discover            Record inspected files and the discovery summary.
    spec-check          Validate the spec against the template and its rules.
    review              Record the spec review (judgment rules, flags, coverage).
    plan-check          Validate plan.md against the plan template.
    approve             Record the user's explicit approval of the spec or plan.
    stage               Move the task to another stage (prerequisites are checked).
    resume              Make a task active again for this session.
    pause               Pause a task; its gates stop applying.
    preflight           Revalidate state and approvals before editing code.
    step                Record progress on an approved plan step.
    run                 Run a configured check and record the evidence.
    scope               Show the task's changes vs. pre-existing work.
    decision            Record a user decision with their words.
    check               Validate records (all tasks, or one).
    outcome             Highest final status the evidence allows, and why.
    close               Close the task with the status written in report.md.
    hook                Agent hook entry points (used by the skill's Claude Code hooks).

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

Stages: DISCOVERY → DEPENDENCIES → SPECIFICATION → SPEC_APPROVAL → PLANNING → PLAN_APPROVAL →
IMPLEMENTATION → TESTING → FIXING → AUDIT → FINAL_REPORT

=== workflow.py init --help ===
usage: workflow.py init [-h] [--repo REPO] [--agent AGENT] [--json] [--discover] [--template TEMPLATE] [--rules RULES] [--no-rules] [--commit {all,config-only,none}] [--standards STANDARDS] [--config CONFIG] [--project-notes PROJECT_NOTES] [--project PROJECT] [--without-check ID] [--add-check ID=COMMAND] [--update]

options:
  -h, --help            show this help message and exit
  --repo REPO           Path inside the project's git repository (default: current directory).
  --agent AGENT         Your agent name: claude-code, codex, gemini-cli, antigravity or other.
  --json                Machine-readable output where supported.
  --discover            Show the setup proposal (or the existing setup) without changing anything.
  --template TEMPLATE   Template file path, or user:<name> from your private library.
  --rules RULES         Template rules file (default: <template>.rules.json next to the template).
  --no-rules            Use structural checks only.
  --commit {all,config-only,none}
                        How task records are committed to git.
  --standards STANDARDS
                        Comma-separated engineering instruction files, e.g. CLAUDE.md,AGENTS.md.
  --config CONFIG       JSON file with checks and rules to start from.
  --project-notes PROJECT_NOTES
                        Markdown file to use as .ai-dev-workflow/PROJECT.md.
  --project PROJECT     Project name.
  --without-check ID    Leave out a recommended check (repeatable).
  --add-check ID=COMMAND
                        Add a check (repeatable).
  --update              Change an existing setup: --commit, --standards, --template, --add-check,
                        --without-check.
